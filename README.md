# 🌸 Shamitha's Dreamy Birthday Website 💗✨

A breathtaking, premium, and focused birthday celebration web application dedicated to **Shamitha**. 

Built with heartfelt appreciation, warmth, elegance, and whimsical magic—crafted specifically to celebrate her happiness, peace, and dreams ahead.

---

## 🎨 Visual Identity & Aesthetic

- **Theme**: Dreamy Pastel Dreamscape
- **Palette**:
  - Blush Pink (`#F8C8DC`)
  - Soft Lavender (`#DCD6FF`)
  - Cloud White (`#FFF9FD`)
  - Pastel Peach (`#FFE1D6`)
  - Champagne Gold (`#E8C98A`)
  - Deep Plum (`#49334F`)
  - Soft Rose (`#E99AB5`)
- **Typography**: *Playfair Display* & *Cormorant Garamond* (Serif headings), *Inter* (Body), *Caveat* & *Dancing Script* (Handwriting).
- **Decorations**: Ambient glowing orbs, drifting clouds, twinkling golden stars, floating rose petals, and interactive floating click hearts.

---

## ✨ Active Sections & Features

1. **Cinematic Opening Screen**:
   - Dreamy gradient sky with drifting clouds, tiny twinkling stars, and floating rose petals.
   - Delicate glowing center heart.
   - Elegant animated text: *"For Someone Truly Special — Shamitha ♡"* and *"Today is your day to shine. ✨"*.
   - Animated glass button: *"Open Your Birthday Surprise 🌸"*.
   - Smooth cinematic fade-in to the main page accompanied by a tasteful pastel confetti burst and gentle music start.

2. **Full-Screen Birthday Hero**:
   - Main heading: *"Happy Birthday, Shamitha! 🎂"*.
   - Subtitle: *"Today is all about celebrating you, your happiness, and all the beautiful things waiting for you."*.
   - Circular floral illustration aura, floating petals, and soft sparkling particles around her name.
   - Dedicated button: *"A Birthday Letter Just for You 💌"* that smoothly glides straight to her letter.
   - Animated scroll indicator.

3. **Interactive 3-Tier Birthday Cake**:
   - Illustrated pastel cake with creamy frosting drips, pearl garlands, and glowing animated candle flames.
   - *"Make a Wish ✨"* button: extinguishes the candles with realistic smoke puffs, launches confetti and stars, and reveals a heartwarming wish.
   - *"Light the Candles Again 🕯️"* button to repeat the celebration.

4. **Heartfelt Birthday Letter with Digital Envelope**:
   - Section heading: *"A Little Letter for You 💌"*.
   - Closed envelope with wax heart seal and gold accents.
   - Smooth envelope unfolding animation that glides open the letter paper.
   - Heartfelt, respectful, warm birthday message revealed paragraph by paragraph.
   - Handwritten signature: *"With lots of heartfelt birthday wishes, Someone who thinks you're truly special ♡"*.

5. **Final Sunset Celebration**:
   - Full-screen lavender and blush sunset finale.
   - *"And one last wish, just for you..."*
   - *"HAPPY BIRTHDAY, SHAMITHA! ♡"*
   - *"May this year bring you happiness, success, and countless beautiful moments."*
   - *"Celebrate Again ✨"* button that launches celebratory confetti and smoothly returns to the opening screen.
   - Footer: *"Made with care, especially for Shamitha. 🌸"*

6. **Floating Music Player & Atmospheric Effects**:
   - Floating glass pill player supporting local `/audio/birthday-music.mp3`.
   - **Zero-Dependency Web Audio Synth**: Automatic fallback to a delicate music-box/celesta birthday chime melody so music always plays reliably.
   - Interactive heart sparkle bursts on click.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev

# 3. Build for production
npm run build
```
Open **[http://localhost:5173](http://localhost:5173)** in any browser.
